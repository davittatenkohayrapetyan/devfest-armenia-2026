# Outreach drafts

Messages that only a human can send. Each one belongs to a board task and blocks something
on the critical path. Placeholders in `[brackets]` need real values — do not guess at a
name, a title or a date and send it anyway.

Keep drafts here rather than in the board so the rows stay terse. Delete a draft once its
task is `done`.
